# WarmDesk v0.2.0 实机暖手测试报告

## 测试时间

2026-11-10 16:35 - 16:40（Asia/Shanghai）

## 测试设备

- MacBook Pro `Mac17,2`
- Apple M5
- 10 个逻辑 CPU
- macOS 27.2
- AC 供电
- 电池约 90%

## 测试方式

- 使用与桌面端相同的 Rust `HeatController` 和 worker pool。
- 暖手强度：28%。
- 模式：恒温。
- 定时：5 分钟。
- 运行结束后由控制器自动停止。

## 结果

- 真实负载持续运行约 295 秒。
- 系统 CPU 采样约 49%～67%，负载期间未触发 CPU 高负载硬停。
- `pmset -g therm` 持续返回无 thermal/performance warning。
- 电源保持 AC，电量保持约 90%。
- CPU 摄氏温度无法通过当前 macOS Apple Silicon 公开接口读取，界面显示“CPU 温度不可用”。
- 结束原因：`定时结束`，未触发过热或热状态保护。

## UI 测试说明

新构建已安装为 `/Applications/WarmDesk-Test.app`，但本轮 macOS ScreenCaptureKit 返回系统级捕捉错误，无法可靠确认图形按钮点击。因此本报告的负载验证使用桌面端同一 Rust 控制器完成，未将 UI 点击路径标记为通过。

## 发布门槛

发布 `v0.2.1` 前需要人工确认：运行测试副本时，将手放在设备键盘/掌托附近，确认热感是否达到预期；若热感仍不明显，再调整目标总 CPU 占比或强度上限。
