# Stitch 暖桌面界面落地记录

## 设计来源

- 工具：Google Stitch MCP
- Stitch 项目：`6083016024979235396`
- 生成方向：WarmDesk Precision Utility
- 设备类型：Desktop
- 目标窗口：约 `420 × 760`

## 已落地的设计决策

- 使用浅冷灰画布、深松绿文字、陶土色动作色和安全绿状态色。
- 使用紧凑桌面工具布局，统一 5-6px 小圆角与 1px 结构线。
- 中央读数只展示“设定强度百分比”，不展示虚构的设备温度。
- 把“模拟原型，不产生实际 CPU 负载和热量”作为首屏持续可见提示。
- 强度范围收敛为 5%-60%，并标注 60% 为建议上限。
- 自动停止提供 30/60/120 分钟快捷按钮。
- 设置抽屉只展示安全边界，不开放风扇、倍频、电压或系统电源策略。

## 工程映射

- `src/App.vue`：状态、强度、模式、计时与安全提示。
- `src/style.css`：Stitch 方案的色彩、边界、间距和紧凑窗口布局。
- `src-tauri/src/lib.rs`：只保留安全运行策略查询命令，未接入真实负载。

## 验收记录

- 420×760 浏览器视口下首屏可见主要操作，无需滚动。
- 开始预览后状态切换为“状态 · 预览中”，运行计时递增。
- 自动停止按钮可选中，设置入口显示真实 CPU 负载/温度传感器/硬件策略均未接入。
- 浏览器控制台错误数为 0。
