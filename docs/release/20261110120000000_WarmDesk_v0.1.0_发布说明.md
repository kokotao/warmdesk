# WarmDesk v0.1.0 发布说明

## 发布范围

WarmDesk v0.1.0 是 macOS 与 Windows 桌面交互原型，包含暖手强度设置、工作模式切换、运行计时、自动停止和安全边界展示。

## 安全说明

此版本不会运行 CPU/GPU 工作负载，不会产生实际热量，也不会修改风扇、电压、倍频或系统电源策略。界面中的强度只用于预览控制交互，不代表实际温度或硬件功耗。

## 安装包

GitHub Actions 在推送 `v*` 标签后为 macOS 与 Windows 构建安装包并上传至对应 GitHub Release。未配置平台代码签名证书时，操作系统可能显示未识别开发者或发布者提示；不要通过关闭系统安全功能安装。

## 已知限制

- 温度传感器、系统负载、电源状态及睡眠/锁屏保护未接入。
- 应用内已提供镜像优先的版本检查与下载入口；镜像不可用时回退 GitHub Release。自动安装、重启升级和下载后完整性校验尚不在桌面端入口内。
- 栗子镜像服务目录和同步任务尚未部署；当前版本检查会回退 GitHub Release。
- macOS 安装包未进行 Developer ID 签名与公证，Windows 安装包未进行 Authenticode 签名。

## 后续方向

- 在确认服务器路径和发布权限后，部署已准备好的栗子镜像同步脚本，并验证 manifest 与每个资产的 SHA-256。
- 为应用内下载增加完整性校验；自动安装和重启升级须等签名验证链完成后再评估。
- 接入可取消、限预算的 Rust 工作线程及平台状态保护后，再评估是否进入真实负载测试。
- 配置代码签名、公证和可验证的自动更新签名链。
