# WarmDesk v0.2.3 发布记录

## 发布目标

修复桌面端点击“下载新版”无实际下载的问题，并提高 macOS/Windows 安装包选择、完整性校验和栗子镜像检查的可靠性。

## 变更

- Tauri 后端新增安装包下载命令，写入系统 Downloads 目录并发出实时进度事件。
- 下载地址仅允许 `note.lizipro.cn`、GitHub 和 GitHub Release 资源域名的 HTTPS 地址。
- 下载文件名限制为安全 ASCII 资产名，禁止路径穿越与查询片段。
- 支持安装包大小和 SHA-256 校验，失败时删除 `.part` 临时文件。
- 根据操作系统与 CPU 架构筛选 DMG、MSI、EXE 安装包。
- 栗子镜像同步脚本增加 `latest.json` 缓存绕过、GitHub 请求重试和可配置超时；Release mirror workflow 调用该脚本完成发布后同步。

## 验证

- `npm run build`：通过。
- `cargo test --locked`：19 个测试通过。
- `bash -n scripts/release-mirror.sh`：通过。
- `git diff --check`：通过。

## 发布范围

- macOS Apple Silicon：由 GitHub Actions 构建。
- macOS Intel：由 GitHub Actions 构建。
- Windows：由 GitHub Actions 构建。
- Release tag：`v0.2.3`

## 已知限制

- 当前未配置 Apple Developer ID、公证或 Windows Authenticode 签名。
- 栗子镜像同步依赖 1Panel 计划任务或 GitHub Actions 的 SSH 配置。
