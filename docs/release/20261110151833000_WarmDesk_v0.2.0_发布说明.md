# WarmDesk v0.2.0 发布说明

## 发布范围

WarmDesk v0.2.0 是首个真实暖手版本，支持 macOS 与 Windows。应用通过可取消、分时的单线程 CPU 工作负载产生设备余热，并提供可调节强度、恒温/脉冲/自适应模式、运行计时和托盘控制。

## 核心能力

- CPU、温度、电源和锁屏状态采样。
- 高系统负载、过热、低电量、锁屏或关键状态不可确认时自动降载或暂停。
- 运行中调整暖手强度和工作模式。
- 深色模式、系统主题跟随和 macOS/Windows 托盘菜单。
- GitHub Release 构建后由 1Panel Shell 计划任务同步到栗子镜像。

## 安全说明

暖手会消耗 CPU 与电量，实际热感取决于设备型号、散热能力和环境温度。应用不修改风扇曲线、电压、倍频或系统电源策略。请保持设备通风，不要覆盖出风口；出现明显高温、风扇持续满速或系统卡顿时立即停止。

## 安装包

GitHub Actions 会为 Apple Silicon macOS、Intel macOS 和 Windows 构建安装包并上传到 GitHub Release。未配置 Apple Developer ID、公证或 Windows Authenticode 签名时，系统可能显示未识别开发者或发布者提示。

## 已知限制

- macOS 不保证提供稳定的公开 CPU 温度接口，温度不可读时会采用保守强度上限。
- Windows ACPI 温度接口依赖硬件和驱动，部分设备可能显示不可用。
- 未提供固定目标温度或固定手部温度承诺。
