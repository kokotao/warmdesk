# WarmDesk v0.2.1 发布说明

## 版本定位

WarmDesk v0.2.1 是 v0.2.0 首个真实暖手版本的安全增强版，面向 macOS 与 Windows 桌面端。

## 主要变化

- 根据逻辑 CPU 核心数换算总 CPU 占比，适配不同核心数的电脑。
- 最多使用 6 个可取消的 CPU 分片 worker，运行中支持强度和模式调整。
- 采集 CPU、温度、电源、锁屏与 macOS thermal warning 状态，并根据状态自动降载或暂停。
- 增加深色模式、托盘控制、热状态展示与 UI 安全免责声明。
- 栗子镜像由 Lingke WSL 上的 1Panel Shell 计划任务每 15 分钟同步。

## 安全边界与免责

本软件通过受控 CPU 工作负载产生设备余热，不是加热器，不保证固定温度、暖手效果或适配所有设备。使用会增加 CPU 占用、功耗、风扇噪声和电池消耗；请保持通风，不要覆盖出风口，并在有人看护时使用。温度采样可能不可用，软件不能替代硬件温控；发现异常发热、异味、噪声、系统不稳定或其他异常时，应立即停止并断开电源。对于设备、环境、供电、系统状态或使用不当导致的损害，作者在法律允许范围内不承担责任；本说明不排除法律规定不得排除的责任。

## 验证状态

- Rust 单元测试、格式检查、Cargo 检查、前端构建和类型检查在发布前执行。
- 已完成 Apple Silicon 实机约 5 分钟受控负载验证；CPU 摄氏温度在当前 macOS 公共接口下不可用，使用 thermal warning、CPU 占用、电源与锁屏状态做保护。
- UI 图形点击路径未作为完整通过项；发布资产由 macOS arm64、macOS x64 与 Windows CI 构建。
