# WarmDesk

WarmDesk 是一个面向 macOS 与 Windows 的桌面暖手工具。它提供可调节的暖手强度、运行模式、计时和状态反馈，并通过可取消、分时的 CPU 工作负载产生设备余热。

## 当前版本

`0.2.1` 是首个真实暖手版本的安全增强版：

- 可以调整强度预算、恒温/脉冲/自适应模式和定时停止。
- 可以开始、停止和重置暖手任务，运行中可调整强度与模式。
- Rust 控制器使用单线程、分时 CPU 工作负载，并支持高负载、过热、低电量和锁屏保护。
- macOS/Windows 桌面端提供 CPU、温度、电源和锁屏状态采样；硬件接口不可用时采用保守降载。
- 真实暖手会消耗 CPU 与电量，实际热感取决于设备散热和环境，不承诺固定温度。

## 安全与免责声明

WarmDesk 仅通过受控 CPU 工作负载产生设备余热，不是加热器，不保证固定温度、暖手效果或适配所有设备。使用时可能增加 CPU 占用、功耗、风扇噪声和电池消耗；请保持通风，不要覆盖出风口，并在有人看护时使用。温度采样可能不可用，软件不能替代硬件温控；发现异常发热、异味、噪声或系统不稳定时，请立即停止并断开电源。对于设备、环境、供电、系统状态或使用不当导致的损害，作者在法律允许范围内不承担责任；本说明不排除法律规定不得排除的责任。

## 设计边界

任何时候都应支持一键停止；传感器不可读、高系统负载、低电量或设备进入睡眠/锁屏时，必须采用保守降载或暂停策略。请保持设备通风，不要覆盖出风口。
