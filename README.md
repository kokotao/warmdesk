# WarmDesk

WarmDesk 是一个面向 macOS 与 Windows 的桌面暖手工具原型。它提供可调节的暖手强度、运行模式、计时和状态反馈，目标是在不修改系统电源策略、风扇曲线或硬件参数的前提下，逐步接入受控的低占用工作负载。

## 当前版本

`0.1.0` 是交互原型：

- 可以调整强度预算、恒温/脉冲/自适应模式和定时停止。
- 可以开始、暂停、重置模拟运行计时。
- 界面明确标注“模拟预览”，当前不会产生实际热量，也不会启动 CPU 负载。
- Tauri Rust 侧只提供运行策略查询命令，不执行危险系统调用。

## 本地开发

```bash
npm install
npm run dev
```

桌面壳开发：

```bash
npm run tauri:dev
```

## 构建检查

```bash
npm run build
cd src-tauri && cargo check
```

## 设计边界

真实负载实现必须放在 Rust 控制器中，并同时接入系统 CPU 负载、电源状态、温度（可选）和睡眠/锁屏事件。任何时候都应支持一键停止；传感器不可读、高系统负载、低电量或设备进入睡眠时，必须采用保守降载或暂停策略。

详细产品规格见 [`docs/spec/20261110024635569_暖桌面跨平台产品规格.md`](docs/spec/20261110024635569_暖桌面跨平台产品规格.md)。
